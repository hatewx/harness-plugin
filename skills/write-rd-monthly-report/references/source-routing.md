## 动态资料发现

1. 用 `lark-drive +search` 搜索报告周期内的部门周报、研发会议周报、项目记录和月报草稿。
2. 对年度滚动文档先取目录，再按日期章节局部读取。
3. 需要“部门所有员工”口径时，先确认部门成员范围，再检查部门周报表格中的人员行；不要假设搜索结果覆盖全员。
4. 对截图、视频和看板，读取对应文档资源块或原始附件；不要从总结文字重新生成“示意图”冒充证据。

## 取证优先级

发生冲突时按以下顺序判断：

1. 产出负责人当周记录或原始看板。
2. 部门研发会议周报。
3. 年度负责人汇总周报。
4. 月报草稿或 AI 总结。

同一层级优先使用更新时间更晚、指标口径更完整的来源。

## 读取边界

- 只读取报告周期相关章节，避免把后续进展写进当月结果。
- 可以用报告截止日之后的修订来纠正事实，但必须确认它描述的是报告期内完成的工作。
- “下月计划”可以来自报告截止日附近的下一周计划；不能把已经在下月完成的结果倒填为上月成果。
