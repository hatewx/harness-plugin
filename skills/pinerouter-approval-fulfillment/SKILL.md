# Token预算审批处理

输入：飞书审批链接。输出：申请表记录、项目和对应环境的 Key。
默认网关：`https://test.sheepwall.com/fe-llm-gateway/`。
字段、随附脚本用法和已知限制见 [operations.md](references/operations.md)；凭据从运行环境读取。

## 1. 读取审批

从链接取得 `instance_code`；短链先解析跳转或在已登录浏览器打开，无法取得时向用户索要完整链接或实例编号。

```bash
lark-cli approval instances get --params '{"instance_code":"<实例ID>","locale":"zh-CN","user_id_type":"open_id"}' --as user
```

仅处理 `APPROVED` 且未撤销的审批。解析 `form`，提取项目、类型、用途、申请人、技术/业务负责人、预算金额与币种、重置周期、起止日期、模型、超限策略、TPM/RPM、Key 环境与 alias。缺项或歧义集中向用户确认，未填速率保持未设置。

## 2. 查重并准备数据

- 读取申请表字段；按审批实例 ID 查记录，按项目名和负责人核对已有项目，读完匹配结果的分页。
- 查询网关 Team、Project、模型及项目 Key；复用匹配项目和已有环境 Key，只创建缺失项。新项目绑定已有 Team。
- 按字段映射准备审批父记录、Key 子记录及父子关联。追加预算列出原额度与新额度，不直接覆盖。
- 保留审批的人民币金额，单独计算网关美元额度并注明汇率依据。明确周期、时区与生效/到期时间；开发、测试、生产按申请使用独立 Key。

## 3. Dry-run 并确认

只读查询后展示具体计划，不调用写接口：

| 对象 | 展示内容 |
| --- | --- |
| 审批 | 链接、实例 ID、状态 |
| 项目 | 目标网关、Team、Project ID，复用或新建及依据 |
| 记录 | 父/子记录新增或补齐，各字段当前值与拟写值 |
| 预算 | RMB、美元额度与换算、周期、起止日期、超限策略 |
| Key | 环境、alias、项目、模型、有效期、TPM/RPM、交付方式 |

列出未解决项和实现限制。用户确认整份计划后才能写入；范围或关键参数变化时重新确认。

## 4. 执行并验证

1. 重新核对审批状态和目标对象，按审批 ID、项目 ID、环境 alias 避免重复创建。
2. 登记或补齐审批父记录，复用或创建项目，再生成缺失的项目 Key。落实审批中的模型、预算与时间约束，未到生效日不提前发放可用 Key。
3. 补齐实际 Key 的子记录与父关联；回读记录、Project 和 Key，核对预算、模型、归属及有效期。
4. 返回记录链接、Project ID、各环境 alias 和执行结果。真实 Key 按确认方式交付，不写入 Base、仓库或普通日志。

失败时停止后续写入，报告已完成对象与待办；响应不确定先查询再补做，不自动删除回滚，不自动通知他人。
