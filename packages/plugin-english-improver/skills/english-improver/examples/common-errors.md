# Common English Errors - Examples

## Grammar Error Examples with Corrections

### 1. Subject-Verb Agreement
**Error:** "The code in these files work correctly."
**Correction:** "The code in these files works correctly."
**Explanation:** "Code" is uncountable and takes singular verb "works"

**Error:** "This algorithms are efficient."
**Correction:** "These algorithms are efficient." or "This algorithm is efficient."
**Explanation:** Singular "this" doesn't match plural "algorithms"

### 2. Article Usage
**Error:** "I need a information about this."
**Correction:** "I need information about this." or "I need some information about this."
**Explanation:** "Information" is uncountable

**Error:** "He is expert in Python."
**Correction:** "He is an expert in Python."
**Explanation:** "Expert" is countable and needs article "an"

### 3. Tense Consistency
**Error:** "I was working on this yesterday and I finish it today."
**Correction:** "I was working on this yesterday and I finished it today."
**Explanation:** Past tense should be consistent

**Error:** "The system will process the data and sends the results."
**Correction:** "The system will process the data and send the results."
**Explanation:** Both verbs should be in future tense form

### 4. Word Order
**Error:** "I don't know what is the problem."
**Correction:** "I don't know what the problem is."
**Explanation:** In embedded questions, use statement word order

**Error:** "Can you tell me where is the bathroom?"
**Correction:** "Can you tell me where the bathroom is?"
**Explanation:** Same rule for embedded questions

## Technical Context Examples

### API Documentation
**Error:** "This endpoint return user data."
**Correction:** "This endpoint returns user data."
**Better:** "This endpoint retrieves user data."

**Error:** "You must to authenticate first."
**Correction:** "You must authenticate first."
**Explanation:** Modal verbs (must, can, should) are followed by base verb

### Code Comments
**Error:** "# This function calculate the average"
**Correction:** "# This function calculates the average"
**Better:** "# This function computes the average"

**Error:** "# Here we are check if user is valid"
**Correction:** "# Here we check if the user is valid"
**Better:** "# Validates the user credentials"

### Error Messages
**Error:** "The system is experiencing a issue."
**Correction:** "The system is experiencing an issue."
**Explanation:** "Issue" starts with vowel sound, needs "an"

**Error:** "Please contact with support team."
**Correction:** "Please contact the support team." or "Please contact support."
**Explanation:** "Contact" is transitive - no preposition needed

## Natural Expression Improvements

### More Native-Like Phrasing

**Instead of:** "I have a doubt about this code."
**Use:** "I have a question about this code." or "I'm not sure about this code."

**Instead of:** "Please solve my doubt."
**Use:** "Can you help me with this question?" or "Could you clarify this?"

**Instead of:** "The code is not working."
**Use:** "The code isn't working." or "The code is failing." or "The code throws an error."

**Instead of:** "It gives me error."
**Use:** "It gives me an error." or "It throws an error." or "It returns an error."

**Instead of:** "I didn't understood."
**Use:** "I didn't understand." or "I don't understand."

**Instead of:** "Can you explain me this?"
**Use:** "Can you explain this to me?" or "Can you explain how this works?"

### Professional Communication

**Instead of:** "I want to ask you something."
**Use:** "Can I ask you something?" or "I have a question."

**Instead of:** "What you think about this?"
**Use:** "What do you think about this?" or "What are your thoughts on this?"

**Instead of:** "I am agree with you."
**Use:** "I agree with you." or "I think so too."

**Instead of:** "I am boring with this task."
**Use:** "I'm bored with this task." or "This task is boring."

## Self-Check Questions

Before asking for help, ask yourself:
1. Did I use the right prepositions?
2. Do my subjects and verbs agree?
3. Are my tenses consistent?
4. Did I use articles correctly (a/an/the)?
5. Does this sound like how native speakers talk?
6. Is this the simplest way to express my idea?
